1. Tables

<table border="1">

<caption>My Time Table</caption>

<thead>
    <tr>
        <th>Time</th>
        <th>Monday</th>
    </tr>
</thead>

<tbody>
    <tr>
        <td>2:30-4:30</td>
        <td>Web Programming</td>
    </tr>
</tbody>

<tfoot>
    <tr>
        <td colspan="2">Total Classes</td>
    </tr>
</tfoot>

</table>

Tables are used to organize information in rows and columns.

  • table creates a table.
  • border="1" adds a border around the table.
  • caption creates a table title.
  • thead contains heading rows.
  • tbody contains table data.
  • tfoot contains summary information.
  • tr creates a row.
  • th creates a heading cell.
  • td creates a data cell.
An Example of a table is shown above, which represents a weekly timetable with time slots and subjects for each day. The table includes a caption, header, body, and footer sections to organize the data effectively:

2. Rowspan and Colspan

<td rowspan="2">Automata</td>

<td colspan="5"></td>

Rowspan makes a cell span multiple rows. Colspan makes a cell span multiple columns.

  • rowspan="2" makes the Automata cell occupy two rows.
  • colspan="5" makes an empty cell stretch across five columns.

15. Semantic Layout Elements

<header>Header</header>

<nav>Navigation</nav>

<main>Main Content</main>

<footer>Footer</footer>

Semantic elements describe the purpose of content on a webpage. They improve readability and organization.

  • header represents introductory content.
  • nav contains navigation links.
  • main contains primary page content.
  • footer contains information shown at the bottom of a page.
