Welcome to my Web Programming project website.

This website demonstrates the concepts learned throughout the course such as HTML including document structure, text formatting, hyperlinks, multimedia, semantic elements, forms, and tables, etc.

The project is organized into multiple pages:

  • Introduction - Provides an overview of the web programming course.
  • Tutorial Vol 1 - Explains fundamental HTML concepts such as headings, paragraphs, images, audio, video, and navigation.
  • Tutorial Vol 2 - Explains slightly more advanced HTML concepts such as tables, forms, semantic elements, rowspan, and colspan.
  • Contact - Contains contact information and links.

Use the navigation menu above or below the page to explore the different concepts and examples. The material will keep expanding as we move furthure along the course.
